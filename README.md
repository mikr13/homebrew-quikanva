# Quikanva Homebrew tap

Homebrew cask for [Quikanva](https://github.com/mikr13/quikanva), a native macOS sketch canvas that is one shortcut away.

```sh
brew trust --tap mikr13/quikanva
brew install --cask mikr13/quikanva/quikanva
```

Quikanva updates itself through Sparkle. The release workflow in [mikr13/quikanva](https://github.com/mikr13/quikanva) updates `Casks/quikanva.rb` after each release, so do not edit it here by hand.
